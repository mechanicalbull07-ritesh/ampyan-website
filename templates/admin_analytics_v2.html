What these numbers mean

TrafficMetric counts eligible public page loads, including visits without analytics consent. A person can load many pages.

Active accounts have at least one recorded feature action beyond login or signup. Anonymous activity and unconsented behavior are not counted as active accounts.

GA4 reports are unavailable here. We never substitute another source for GA4.

{% endif %} {% if section == 'traffic' %}

How traffic is classified

Human-like

Recognised browser signals plus document-navigation headers. This does not prove a human.

Likely bot

Existing crawler, automation, monitoring or headless user-agent markers. Bots can hide these signals.

Unclassified

Signals are insufficient. These requests are not reassigned to humans or bots.

Only eligible public GET requests returning origin-served HTML 200 are counted. Admin, internal, private, prefetch and non-document requests are excluded by the accepted classifier. CDN-served requests may not reach the origin.

Data sources & coverage
TrafficMetric
Anonymous hourly origin page-load counts. No visitor identities. Today uses stored UTC buckets starting at {{ summary.traffic_start_ist }}.
WebsiteVisit
{{ '{:,}'.format(summary.website_views) }} qualifying consented page-view records from {{ summary.window_start_ist }}. Separate from TrafficMetric; never added to it. Historical flag handling follows the existing dashboard.
AnalyticsEvent
{{ '{:,}'.format(summary.event_records) }} qualifying action records in the selected period. Stored web/app channels remain separate. FALSE bot/internal/admin flags are required, as in the existing live summary.
Registered accounts
Current non-admin, non-managed-persona account count. All time; no signup timestamp exists in the account model.
Meaningfully active accounts
Distinct eligible registered account IDs with a canonical feature action other than signup or login. A consented subset, not all active visitors.
Included actions
